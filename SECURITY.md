# Security Policy

## Supported Versions

We recommend that you use the latest stable version. A version comes in the form:

```
X.Z.Y
```

Where **X** is the release version (it should always be `0`), **Z** is the number of the stable version, and **Y** is the number of the `nightly` (`patch`).
\
So we recommend to use the version in the highest value of **Z**.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.4   | :white_check_mark: |
| 0.0.3   | :white_check_mark: |
| 0.0.2   | :x: |
| 0.0.1   | :x:                |

## Reporting a Vulnerability

When reporting a vulnerability, **don't** open an issue. Please contact me on discord : `vram_ram`, and explain in details the security break.
